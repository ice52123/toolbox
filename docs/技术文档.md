## 1. 项目速览

### 1.1 它是什么

一个面向校园的聚合前端站（**校园集 / CampusToolBox**），主要内容：

1. **工具箱**：22 个纯前端小工具（JSON 格式化、时间戳、Base64、哈希、进制、正则、JWT、图片压缩/转换/水印、PDF 合并/拆分、密码、UUID、颜色、单位换算、万年历、汇率、天气、快递、油价、公交）。
2. **校园社区**：P3 校园社区（板块 + 帖子列表 / 详情 / 发帖 / 评论 / 点赞 / 收藏 / 搜索）。
3. **闲置市场**：qiankun 微前端子应用（`/m/idle`），自身是独立 Vue 应用，含发布 / 列表 / 详情 / 订单。
4. **社交与交易**：好友、私聊、订单闭环（下单 → 发货 → 收货 → 评价）、钱包、收货地址。
5. **多租户校园**：顶部「校园切换器」+ `/api/schools`，内容按校区隔离。

另有两个 Express 后端（MySQL 版 / MongoDB 版）作为双后端实验，**接口契约一致、同一套前端可切换**：已落地用户 / 工具 / 上传 / 学校 / 首页 / 社区 / 帖子 / 个人 / 闲置 / 订单 / 消息 / 聊天 / 好友等模块（MySQL 版约 60+、Mongo 版约 45+ 条接口，详见 `docs/API-清单.md`）。qiankun 还注册了 `campus-forum`(P3) / `message-center`(P5) 两个占位子应用。

### 1.3 端口总表

| 服务 | 端口 | 说明 |
|---|---|---|
| client（主应用） | 5173 | `npm run dev`；生产由云端单端口（默认 3000）托管 |
| idle-market（子应用） | 4200 | qiankun 独立运行时；**必须复用 4200**，宿主写死连它 |
| server（MySQL） | 3201 | 主站 `/api` 代理目标 |
| server-mongo | 3202 | 切到 Mongo 版时改 vite proxy |
| 子应用构建基址 | `/idle-app/` | idle-market/vite.config.js 的 `base` |
| 子应用运行时 base | qiankun 内 `/m/idle`、独立 `/` | idle-market/src/router/index.js |
| 静态文件前缀 | `/files` | 两个后端一致 |

### 1.4 技术栈总表（client）

| 类别 | 选型 |
|---|---|
| 框架 | Vue 3.5（`script setup` 组合式 API） |
| 路由 | vue-router 4，`createWebHistory`（history 模式），全页面懒加载 |
| 状态 | Pinia（theme / ui / user 三个 store） |
| UI | Element Plus 2.8（全量引入，不走按需插件） |
| 图标 | @element-plus/icons-vue 2.3（main.js 里遍历全量注册） |
| 样式 | Less 4.9 + CSS Modules（`ui.module.less` 共享原子类 + 各页 `<style module>` 局部类） |
| 构建 | Vite 5（`@` → `src` 别名） |
| 微前端 | qiankun 2.10 |
| HTTP | axios 1.7（仅 `utils/request.js`） |
| PDF | pdf-lib 1.17（**动态 import 懒加载**，不进主包） |
| 农历 | solarlunar 3.1（仅万年历静态引入） |
| 云服务 | @tencent-ai/workbuddy-cloud-sdk（仅 `utils/cloud.js` 单点初始化，未接入业务） |

**刻意不用的库**（别顺手加）：crypto-js / js-md5（MD5 是手写的）、uuid / nanoid（用 `crypto.randomUUID`）、tinycolor（颜色公式手写）、he（用 `escape/unescape`）、FileSaver.js（用原生 `<a download>`）、compressjs / sharp（图片全走浏览器 Canvas）、convert-units（单位因子表手写）。

### 1.5 本地启动

```bash
# 主站（5173）
cd client && npm run dev

# 闲置市场子应用（4200，不启则 /m/idle 走诊断提示）
npm --prefix idle-market run dev

# 两个后端二选一
npm --prefix server start        # 3201，MySQL
npm --prefix server-mongo start  # 3202，MongoDB
```

MySQL 侧的库表初始化写在 `server/sql/init.sql`（`toolbox` 库，2 张表：`users` / `tool_history`）。
